# Bar X Ranch — 4-Lot Feasibility Portfolio (reviewed &amp; rebuilt)

Independent review and correction of a generated 9-page feasibility portfolio for four vacant
lots in Bar X Ranch, Angleton (unincorporated Brazoria County), TX 77515 — evaluated for a
5-bedroom build with private-lake access and Zone AE flood exposure.

## Headline corrections vs. the original

- **Septic drainfield** was undersized 3–6× (its loading rate exceeded every TCEQ soil class); the
  likely aerobic system and its $15k–$25k cost were missing entirely.
- **County permit fee** was overstated ~7–11× and double-counted (~$165 actual, one combined permit).
- **Pre-construction cost** ~$26k–$108k, not $11k–$17k; **the house itself** ($420k–$700k) was absent.
- **Windstorm insurance, property tax, and POA carry** were omitted; corrected carry ≈ $5k–$5.8k/yr on
  four vacant lots, and all-in build ≈ $490k–$890k on one lot.
- **Flood, LOMA, fishing-license, and "Zoning 0140"** claims corrected against FEMA, TCEQ, TPWD and county records.
